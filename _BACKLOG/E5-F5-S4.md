# E5-F5-S4 Start new and duplicated roles in inline edit mode

## User Story

As a designer, I want newly added or duplicated roles to immediately expose their tab label as an editable text field so that I can name them without hunting for a separate control.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F5](./E5-F5.md) - Role toolbar ergonomics and default Material roles feature.

## Scope

- Enter inline tab rename mode after adding a custom role.
- Enter inline tab rename mode after duplicating a role.
- Select the generated label text so typing replaces it immediately.
- Keep the generated fallback label if the user exits edit mode without a valid new name.
- Preserve duplicate role tonal settings and preview settings while only editing the label.

## Acceptance Criteria

- Adding a role creates it, selects it, and focuses its tab label text field.
- Duplicating a role creates it, selects it, and focuses its tab label text field.
- Typing a valid label and pressing Enter commits the new label.
- Blurring the field with no valid change keeps a safe generated label.
- Tests cover add and duplicate flows entering inline edit mode.
