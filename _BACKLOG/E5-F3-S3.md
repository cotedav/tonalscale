# E5-F3-S3 Share dynamic roles through URL, import, and export flows

## User Story

As a designer, I want URLs, JSON import/export, and SVG export to include custom roles so that collaborators receive the same complete palette.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F3](./E5-F3.md) - Dynamic role persistence and sharing feature.

## Scope

- Update URL synchronization to encode the dynamic role schema.
- Update the import/export modal to show and accept complete dynamic role payloads.
- Update SVG export metadata and visible role labels to identify the active role and preserve all role data.
- Ensure delayed URL updates do not cause exports to miss recent role changes.
- Keep export strings recoverable even when SVG visual text is clipped by renderers.

## Acceptance Criteria

- A palette with custom roles can be shared by URL and restored exactly.
- JSON export/import preserves role order, metadata, active role, and every role configuration.
- SVG export preserves the complete dynamic payload in metadata and includes the active role label visibly.
- Export immediately after editing a role includes the latest state.
- Tests cover URL, modal import/export, and SVG export for palettes with custom roles.
