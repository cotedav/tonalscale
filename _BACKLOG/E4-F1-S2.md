# E4-F1-S2 Generate and retain independent tonal scales for each role

## User Story

As a designer, I want a generated tonal scale for both surface and primary colors so that both roles remain available while I work.

## Related Epic

- [E4](./E4.md) - Multi-role tonal color system epic.

## Related Feature

- [E4-F1](./E4-F1.md) - Role-aware tonal configuration and generation feature.

## Scope

- Generate full, extended, and key strips independently from each role's configuration.
- Reuse the existing tonal engine and derived metadata for both roles.
- Recompute only the role whose parameters change.
- Keep both generated results available to the preview and persistence layers regardless of the active editing role.
- Preserve role-specific derived data such as luminance, contrast metadata, and blend distribution.

## Acceptance Criteria

- Surface and primary expose independent full, extended, and key strips.
- Changing surface regenerates surface output without changing primary output, and vice versa.
- Switching tabs does not trigger a reset or cross-role regeneration.
- Both roles remain available to consumers when either role is active.
- Unit tests verify independent generation and derived metadata for both roles.
