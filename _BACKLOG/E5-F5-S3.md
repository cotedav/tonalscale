# E5-F5-S3 Rename roles inline from the selected tab

## User Story

As a designer, I want to click an already selected color role tab to edit its label inline so that renaming a role happens where I am already focused.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F5](./E5-F5.md) - Role toolbar ergonomics and default Material roles feature.

## Scope

- Replace the separate role name field and checkmark action with inline tab label editing.
- Enter edit mode when the user clicks the currently selected role tab.
- Confirm the rename when the user presses Enter or moves focus/clicks outside the field.
- Cancel or preserve the current label when the user leaves the field empty or enters an invalid duplicate.
- Keep validation feedback accessible and localized.

## Acceptance Criteria

- Clicking an unselected tab selects it without entering rename mode.
- Clicking the already selected tab turns its label into a text field.
- Pressing Enter confirms a valid rename and returns the tab to display mode.
- Clicking outside confirms a valid rename and returns the tab to display mode.
- Empty or duplicate labels are rejected with accessible feedback and do not corrupt role metadata.
- The old standalone role name field and checkmark button are removed.
