# E4-F4-S3 Import and export complete multi-role configurations

## User Story

As a designer, I want JSON import and export to include surface and primary gradients so that I can archive and exchange the complete setup.

## Related Epic

- [E4](./E4.md) - Multi-role tonal color system epic.

## Related Feature

- [E4-F4](./E4-F4.md) - Multi-role URL and import/export persistence feature.

## Scope

- Export the canonical versioned schema with both role configurations and durable preview settings.
- Import and validate new multi-role payloads as one atomic state change.
- Migrate existing single-color export files into the surface role and provide a default primary role.
- Ensure imported state refreshes both role workspaces, generated scales, role cards, and the combined app preview.
- Provide clear success, migration, validation, and unsupported-version feedback.

## Acceptance Criteria

- Exported JSON contains schema version, surface, primary, and durable preview settings.
- Re-importing an export restores the identical controls, scales, active tab, and preview colors.
- Legacy single-color JSON imports successfully through the documented migration.
- Invalid imports do not partially update either role.
- Tests cover current-schema round trips, legacy migration, invalid payloads, and unsupported versions.
