# E5-F4-S2 Showcase additional roles in the app preview

## User Story

As a designer, I want the app preview to include believable examples for additional color roles so that I can evaluate custom roles without replacing the core surface palette.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F4](./E5-F4.md) - Dynamic role preview and export integration feature.

## Scope

- Keep the main preview shell driven by the surface role.
- Render role showcase sections for non-surface roles in a scalable way.
- Include light and inverse examples, outline examples, and text/on-surface examples for each showcased role.
- Avoid overcrowding the preview when many custom roles exist by using a compact or scroll-aware presentation.
- Keep hover tooltips and role cards aligned with the showcased surfaces.

## Acceptance Criteria

- Surface remains the base palette for the main app preview.
- Primary and custom roles appear as additional showcase content rather than replacing the shell surfaces.
- Each showcased role includes at least one light surface, one inverse surface, and outline/on-surface examples.
- The preview remains usable when several custom roles exist.
- Component tests cover custom role showcases and hover metadata.
