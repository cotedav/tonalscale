# E5-F7-S3 Swap two color role configurations

## User Story

As a designer, I want to swap two role configurations in one action so that I can test which color works best for a built-in Material purpose without manually rebuilding both roles.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F7](./E5-F7.md) - Palette workflow, persistence, and preview fidelity feature.

## Depends On

- [E5-F5-S5](./E5-F5-S5.md) - Add default Secondary, Tertiary, and Error roles.
- [E5-F6-S4](./E5-F6-S4.md) - Customize selected surface card tones with the mouse wheel.

## Scope

- Add an accessible action for choosing a source role and target role to swap.
- Swap the complete configuration for both roles, including base color, blend color, blend mode, tonal controls, preview settings, surface tone/contrast settings, and custom surface tone overrides.
- Keep each role's identity, label, order, built-in/custom metadata, and preview purpose unchanged.
- Prevent invalid swaps such as selecting the same role twice.
- Update URL/local storage/import-export state after the swap.

## Acceptance Criteria

- Swapping Primary and Secondary makes Primary use Secondary's previous configuration and Secondary use Primary's previous configuration.
- Built-in role labels and preview purposes do not move.
- Custom surface tone overrides move with the swapped configurations.
- The active role remains predictable after the swap.
- Tests cover built-in role swaps, custom role swaps, invalid same-role swaps, and persistence after reload/import.
