# E5-F5-S9 Polish color control labels for production readiness

## User Story

As a designer, I want the color controls panel labels to sound user-friendly and professional so that the app feels ready to deploy instead of exposing internal implementation language.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F5](./E5-F5.md) - Role toolbar ergonomics and default Material roles feature.

## Scope

- Review labels, helper text, aria labels, and section titles in the color controls panel.
- Keep the existing control names where they are clear, but remove unnecessary repetition such as repeated "Blend" prefixes inside the blend section.
- Replace developer-centric wording with concise product copy.
- Update all locales together.
- Preserve existing control behavior and layout.

## Acceptance Criteria

- Color control labels are concise, human-friendly, and consistent across the panel.
- The blend controls do not repeat "Blend" where the surrounding section already establishes context.
- User-facing strings are localized through the existing i18n dictionaries.
- Tests that assert visible labels or accessible names are updated.
- No control IDs, persistence keys, or import/export schema fields are renamed as part of this copy polish.
