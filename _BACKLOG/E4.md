# E4 Multi-role tonal color system epic

## Epic Statement

As a design systems practitioner, I want to define independent tonal gradients for surface and primary colors so that I can evaluate a more complete Material color system in one persistent app preview.

## Goals

- Add a primary color tonal gradient alongside the existing surface color gradient.
- Let users switch the editing workspace between surface and primary colors without losing either configuration.
- Keep the app preview live and composed from both color roles while either role is being edited.
- Preserve both role configurations through URLs, imports, and exports.
- Maintain backward compatibility with existing single-color URLs and exported JSON.

## Deliverables

- [E4-F1](./E4-F1.md): Role-aware tonal configuration and generation.
- [E4-F2](./E4-F2.md): Surface and primary editing tabs.
- [E4-F3](./E4-F3.md): Combined Material role preview.
- [E4-F4](./E4-F4.md): Multi-role URL and import/export persistence.
