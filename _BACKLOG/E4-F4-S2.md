# E4-F4-S2 Synchronize both color roles with shareable URLs

## User Story

As a designer, I want shared URLs to restore surface and primary gradients so that collaborators see the same complete color system.

## Related Epic

- [E4](./E4.md) - Multi-role tonal color system epic.

## Related Feature

- [E4-F4](./E4-F4.md) - Multi-role URL and import/export persistence feature.

## Scope

- Extend URL serialization to include both role configurations using the canonical versioned schema.
- Restore both roles, durable preview settings, and the active editing tab on initial navigation.
- Keep URL updates atomic so a link never represents a partially updated role.
- Maintain support for existing single-color URLs through the migration path.
- Define a compact encoding strategy and guard against invalid or excessively large query payloads.

## Acceptance Criteria

- Copying and opening the current URL restores identical surface and primary configurations.
- The restored preview uses both saved color roles before the user edits anything.
- Legacy single-color URLs continue to load as surface configurations with a default primary.
- Invalid URL data falls back safely and provides appropriate user feedback.
- Tests cover multi-role round trips, legacy URLs, invalid data, and active-tab restoration.
