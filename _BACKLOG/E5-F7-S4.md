# E5-F7-S4 Apply one role configuration to another role

## User Story

As a designer, I want to copy one role's configuration into another role so that I can use a proven color setup as a starting point for a harmonious palette.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F7](./E5-F7.md) - Palette workflow, persistence, and preview fidelity feature.

## Depends On

- [E5-F7-S3](./E5-F7-S3.md) - Swap two color role configurations.

## Scope

- Add an accessible action for choosing a source role and destination role.
- Overwrite only the destination role's editable color configuration with the source role's configuration.
- Keep the destination role's identity, label, order, built-in/custom metadata, and preview purpose unchanged.
- Include base color, blend color, blend mode, tonal controls, preview settings, surface tone/contrast settings, and custom surface tone overrides in the copied configuration.
- Require confirmation or clear affordance before overwriting an existing destination configuration.

## Acceptance Criteria

- Applying Primary to Secondary makes Secondary match Primary's current editable configuration.
- Primary remains unchanged after the apply action.
- Destination labels and Material preview purpose stay attached to the destination role.
- Custom surface tone overrides are copied to the destination role.
- Tests cover overwrite behavior, cancel/confirmation behavior, custom roles, and persistence after reload/import.
