# E4-F3-S1 Map the primary gradient to Material primary roles

## User Story

As a designer, I want the primary gradient mapped to Material primary roles so that the preview uses meaningful primary, container, and foreground colors.

## Related Epic

- [E4](./E4.md) - Multi-role tonal color system epic.

## Related Feature

- [E4-F3](./E4-F3.md) - Combined Material role preview feature.

## Scope

- Define documented light and dark mappings for Primary, On Primary, Primary Container, and On Primary Container.
- Source every mapped role from the primary tonal scale.
- Add at-a-glance role cards for the primary roles with tone and hex values.
- Include primary roles in the existing app-preview hover inspector.
- Keep mapping definitions testable and separate from preview markup.

## Acceptance Criteria

- All four Material primary roles resolve to documented tones in light and dark modes.
- Role cards show the active tone and hex value for each primary role.
- Hovering a primary-colored preview element identifies its role and tone.
- Primary mappings update immediately when the primary gradient changes.
- Unit tests cover light/dark mappings and reactive updates.
