# E5-F4-S3 Export dynamic role surface cards and tone mappings

## User Story

As a designer, I want exports to include surface cards and tone mappings for dynamic roles so that exported artifacts communicate how every palette role is applied.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F4](./E5-F4.md) - Dynamic role preview and export integration feature.

## Scope

- Include active role surface cards in SVG export using generic role labels.
- Preserve complete dynamic role data in SVG metadata.
- Consider an export layout that can include summaries for multiple roles without becoming unreadable.
- Keep tone labels under tonal strips and exported color labels consistent for built-in and custom roles.
- Ensure custom role names are XML-escaped and visually safe in exports.

## Acceptance Criteria

- Exporting any role labels the exported color with that role's user-facing label.
- Surface cards are generated from the active role's dynamic surface mapping.
- Custom role names and payload data are XML-safe in the exported SVG.
- Exports preserve complete role data in metadata even when visible text is clipped.
- Tests cover SVG export for custom roles, special characters in labels, and active-role switching.
