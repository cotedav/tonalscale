# E5-F7-S2 Export customized surface role values in SVG

## User Story

As a designer, I want SVG exports to use my manually customized surface tones so that exported artifacts match the palette I validated in the app.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F7](./E5-F7.md) - Palette workflow, persistence, and preview fidelity feature.

## Depends On

- [E5-F6-S4](./E5-F6-S4.md) - Customize selected surface card tones with the mouse wheel.
- [E5-F7-S1](./E5-F7-S1.md) - Store share state locally instead of in base64 URLs.

## Scope

- Update single-role SVG export to use customized surface role tones for the current light/dark mode when present.
- Update all-roles SVG export to use each role's customized surface role tones independently.
- Preserve automatic tone assignment for roles without custom overrides.
- Ensure exported tone labels, swatches, and surface cards all agree on the final tone and hex value.
- Include enough metadata in the import JSON footer to restore customized surface tones.

## Acceptance Criteria

- Customized surface cards in the UI export with the same tone number and hex value in SVG.
- Non-customized surface cards continue to export automatic values.
- All-roles SVG export respects customizations per role and per light/dark mode.
- Removing a customization restores automatic SVG output.
- Tests cover single-role export, all-roles export, and mixed customized/automatic roles.
