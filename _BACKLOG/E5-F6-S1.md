# E5-F6-S1 Exclude the base-adjacent tone from key strips and assignments

## User Story

As a designer, I want the Extended Strip and Key Strip to omit any tone stop that is the closest generated color to the base color so that role assignments do not accidentally reuse a color that visually represents the authored base rather than a distinct tonal step.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F6](./E5-F6.md) - Surface role tone assignment and customization feature.

## Scope

- Detect the nearest key-strip stop to the current base color tone when one exists.
- Remove that tone from the Extended Strip and Key Strip display for the active color role.
- Ensure automatic surface role assignment ignores the same removed tone.
- Keep the Full Scale Strip unchanged so users can still inspect every generated tone.
- Apply the rule consistently to built-in and custom color roles.

## Acceptance Criteria

- If the base color is closest to tone 40, tone 40 is absent from the Extended Strip and Key Strip for that role.
- The removed tone is not assigned to surface cards by automatic mapping.
- The Full Scale Strip still shows the removed tone.
- Changing the base color recalculates which strip tone, if any, should be removed.
- Tests cover strip rendering and surface assignment with a base tone between two key stops.
