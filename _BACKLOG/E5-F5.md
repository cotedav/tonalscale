# E5-F5 Role toolbar ergonomics and default Material roles feature

## Feature Statement

As a designer, I want the color role toolbar to behave like a direct-manipulation tab system and include the standard Material color roles by default so that building a complete palette feels fast, discoverable, and aligned with Material Design.
