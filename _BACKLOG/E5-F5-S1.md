# E5-F5-S1 Place add role action in the tab toolbar

## User Story

As a designer, I want the add color role button next to the role tabs so that creating a role feels connected to the tab list it affects.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F5](./E5-F5.md) - Role toolbar ergonomics and default Material roles feature.

## Scope

- Move the add color role action from the role management controls into the tab toolbar.
- Present the add action as an icon button visually aligned with the tabs.
- Keep the existing accessible name and keyboard reachability for adding a role.
- Preserve the current add role store behavior, including default role state creation.
- Remove any now-redundant add control from the separate management area.

## Acceptance Criteria

- The add color role button appears immediately next to the color role tabs.
- The add action remains keyboard accessible and has a localized accessible label.
- Clicking the add button creates a new custom role and selects it.
- No duplicate add role buttons remain in the toolbar.
- Existing role creation tests are updated for the new control location.
