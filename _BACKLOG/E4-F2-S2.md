# E4-F2-S2 Bind the tonal workspace to the active color role

## User Story

As a designer, I want the controls and tonal strips to follow the selected tab so that I can edit surface or primary with the same tools.

## Related Epic

- [E4](./E4.md) - Multi-role tonal color system epic.

## Related Feature

- [E4-F2](./E4-F2.md) - Surface and primary editing tabs feature.

## Scope

- Bind color pickers, blend controls, tonal strips, accessibility previews, and contextual interactions to the active role.
- Populate every control from the selected role immediately when tabs change.
- Route user changes only to the selected role.
- Clear or reconcile transient hover and selected-tone state when switching roles to avoid displaying metadata from the previous scale.
- Preserve panel sizing, scrolling, and open picker behavior while tabs change.

## Acceptance Criteria

- Selecting Surface shows the saved surface values and generated strips.
- Selecting Primary shows the saved primary values and generated strips.
- Editing the active workspace updates only its selected role.
- Switching repeatedly between roles restores the exact control values previously entered for each role.
- Accessibility and selected-tone data always correspond to the visible role.
- View and component tests cover role switching and independent edits.
