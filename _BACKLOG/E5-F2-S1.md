# E5-F2-S1 Render role tabs from dynamic role order

## User Story

As a designer, I want the toolbar role tabs to reflect all available color roles so that I can switch between built-in and custom roles consistently.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F2](./E5-F2.md) - Role management experience feature.

## Scope

- Render role tabs from the store's ordered role ids instead of a hardcoded role array.
- Keep color badges, active state, keyboard navigation, and accessible tab semantics working for any number of roles.
- Support horizontal overflow or responsive behavior when many roles exist.
- Use localized built-in role labels and user-defined labels for custom roles.
- Preserve the current surface and primary appearance when only built-in roles exist.

## Acceptance Criteria

- Surface and primary render exactly as before when no custom roles exist.
- Additional roles appear in the configured order with their color badges.
- Keyboard navigation works across all visible roles, including first/last behavior.
- Tab labels and badges remain accessible and localized where applicable.
- Component tests cover rendering three or more roles and keyboard navigation across them.
