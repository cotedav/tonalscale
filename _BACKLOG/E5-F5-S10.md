# E5-F5-S10 Fix the import dialog title translation

## User Story

As a designer, I want the import dialog to show a proper localized title so that the modal feels polished and does not expose a raw translation key.

## Scope

- The import dialog title renders as readable localized text.
- The raw key `tonal_builder.modals.dialog_title` is never shown in the UI.
- The dialog has an accessible name matching the localized title.
- Unit tests cover the translated title.
