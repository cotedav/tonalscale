# E5-F5-S7 Reset the app to its initial state

## User Story

As a designer, I want a reset button for the whole app so that I can quickly return to the initial palette, role order, preview settings, and sharing state.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F5](./E5-F5.md) - Role toolbar ergonomics and default Material roles feature.

## Scope

- Add a reset action to the main toolbar.
- Reset all color roles, role order, active role, tonal controls, preview settings, and selected swatches to the initial defaults.
- Clear or replace the current share URL state so it no longer restores the previous configuration.
- Ask for confirmation before resetting if the current state differs from the initial state.
- Keep the reset action accessible and localized.

## Acceptance Criteria

- Clicking reset restores the same state as a fresh app load.
- The reset includes built-in roles, custom roles, role order, color settings, preview settings, and active selection.
- The URL/share state reflects the reset state after reset completes.
- The user is protected from accidental reset when unsaved changes are present.
- Unit tests cover reset behavior in the store and the toolbar.
