# E5-F5-S8 Export one role or all roles from a menu

## User Story

As a designer, I want the export action to let me choose between exporting the current role or all roles so that I can copy either a focused palette artifact or the complete design-system palette in one action.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F5](./E5-F5.md) - Role toolbar ergonomics and default Material roles feature.

## Scope

- Replace the direct export button behavior with a menu.
- Add menu choices for "This role only" and "All roles".
- Keep the current single-role SVG export available through "This role only".
- Add an all-roles SVG export that includes every role's tonal strips, surface mappings, and metadata in one copied SVG string.
- Preserve complete import/share metadata in both export modes.

## Acceptance Criteria

- Clicking Export opens an accessible menu with "This role only" and "All roles".
- Selecting "This role only" copies the same focused-role SVG export currently available.
- Selecting "All roles" copies one SVG containing every role in role-order sequence.
- All-roles export clearly labels each role and includes role-specific tone strips and surface cards.
- Tests cover both export menu options and verify all built-in and custom roles are represented.
