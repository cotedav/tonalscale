# E5-F2-S2 Add and duplicate color roles

## User Story

As a designer, I want to add new color roles or duplicate an existing role so that I can quickly explore additional palette roles.

## Related Epic

- [E5](./E5.md) - Dynamic tonal color roles epic.

## Related Feature

- [E5-F2](./E5-F2.md) - Role management experience feature.

## Scope

- Add a role creation action in the toolbar or role management menu.
- Create custom roles with a default tonal configuration and default preview settings.
- Allow duplicating the active role, including tonal controls and preview settings.
- Generate unique labels and ids for new or duplicated roles.
- Make the new role active after creation.

## Acceptance Criteria

- Users can add a custom role without disrupting built-in roles.
- Users can duplicate any role and receive an independent editable copy.
- New roles get unique ids, labels, tonal state, and preview settings.
- The newly added or duplicated role becomes the active editing role.
- Unit and component tests cover add, duplicate, uniqueness, and state independence.
