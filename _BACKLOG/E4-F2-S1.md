# E4-F2-S1 Add accessible surface and primary toolbar tabs

## User Story

As a designer, I want surface and primary tabs in the main top toolbar so that I can clearly choose which color role I am editing.

## Related Epic

- [E4](./E4.md) - Multi-role tonal color system epic.

## Related Feature

- [E4-F2](./E4-F2.md) - Surface and primary editing tabs feature.

## Scope

- Add Surface and Primary tabs to the main application toolbar.
- Use an accessible tab pattern with visible selected, hover, focus, and disabled states.
- Support pointer and keyboard navigation according to ARIA tab guidance.
- Localize tab labels in every supported locale.
- Keep import, export, and application theme controls available in the toolbar.

## Acceptance Criteria

- The toolbar clearly identifies Surface and Primary as editing destinations.
- The active tab is visually distinct and programmatically exposed.
- Users can switch tabs using pointer and keyboard input.
- Tab labels are localized and do not introduce missing i18n keys.
- Component tests cover rendering, selection, and keyboard interaction.
